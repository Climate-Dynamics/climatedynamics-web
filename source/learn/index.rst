Learn
=====

The resources on this page help you learn about climate and atmospheric science, coding, and geohazards. They are free, open-access, open-source, and created with love and the help of people from the Climate Dynamics Lab.

.. grid:: 1 2 3 3
   :gutter: 3

   .. grid-item-card:: Building a Climate
      :img-top: img/banner001_ccby_SebastianMutz.jpg
      :img-alt: Building a Climate
      :link: climate/index
      :link-type: doc

      A series of lessons (part of the INTEGRATE teaching package) that introduces the climate system step-by-step. The lessons take you from large-scale controls on the climate system to small-scale processes.

   .. grid-item-card:: Coding for Beginners
      :img-top: img/integrateLogo196x196_ccby_SebastianMutz.jpg
      :img-alt: Coding Exercvises
      :link: code/index
      :link-type: doc

      A small set of coding exercises for absolute beginners! The materials go over some important concepts like data types, constructs, and basic maths. The exercises are available for Fortran and Python.

   .. grid-item-card:: ParsQuake Video Lessons
      :img-top: img/parsquake_512x512.png
      :img-alt: ParsQuake
      :link: https://parsquake.org/
      :link-type: url

      A series of videos for emergency Earthquake education. These are suitable for teachers to use in the classroom and follow the MIT Blossoms teaching duet pedagogy.

..    .. grid-item-card:: ITNEGRATE
..       :img-top: img/integrateLogo196x196_ccby_SebastianMutz.jpg
..       :img-alt: INTEGRATE
..       :link: https://integrate.mutz.science/
..       :link-type: url
..
..       A complete teaching package for physical climatology, empirical methods and a hands-on approach of collecting and analysing atmospheric data. It includes lectures, exercises, syllabus, and a teacher guide.
